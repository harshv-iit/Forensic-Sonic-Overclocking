# Forensic-Sonic-Overclocking
FFmpeg-powered audio processing toolkit for Termux featuring crossfeed, stereo widening, mid/side mastering, loudness normalization, stem extraction, and batch album processing.

Experimental audio DSP toolkit for Android/Termux using FFmpeg.

## Features

- Meier crossfeed
- SPL Phonitor-style crossfeed
- Mid/Side stereo processing
- Stereo widening
- Loudness normalization
- Stem extraction
- Batch album processing
- Loudness auditing

## Requirements

- Android 8+
- Termux
- FFmpeg
- FFprobe

## Folder Structure

/sdcard/Music
/sdcard/Music (processed)

## Usage

far "song.flac"

uw "song.flac"

rip "song.flac"
